# ADR-041: Benchmark separates effect semantics from agent quality

Status: accepted

The first public benchmark is deterministic and synthetic. It compares release, duplication, approval, and recovery semantics across direct execution, permission-only, sandbox-only, and FutureDiff modes. It does not claim to measure LLM intelligence, token use, provider latency, or end-to-end task quality. Real-agent and real-provider benchmarks are a later layer.
